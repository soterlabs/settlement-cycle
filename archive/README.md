# Archived material

Historical material retained for reference, outside the active settlement report pipeline.

- `preparation/`: MSC#9 preparation document and its standalone generators.
- `reference/`: historical OBEX SQL reconciliation oracle. Local, untracked PnL reference copies may also be present.
- `docs/pricing/`: historical allocation and holding-address inventories used when configuring venues. Runtime configuration lives in `config/`.

These files are not maintained against the current settlement methodology. Preparation scripts may require their historical external data sources.
