# PR #282 review and fixes

## Round 1 — reviewed head 6e3459c

- **P1:** The gate compared debt and deduction inputs but ignored the saved
  `utilized` borrowing principal. A stale principal could therefore pass with
  correct holdings. The gate now compares it with independently observed debt
  minus all seven deductions. Legitimate negative principal remains valid;
  the existing charging formula continues to clamp it when calculating fees.
- **P2:** `int(raw, 16)` accepted separators inside a 32-byte provider response.
  Archive balances now require exactly 64 hexadecimal digits after `0x`.
- **P2:** The per-account cent allowance could accumulate into a larger
  unsupported aggregate deduction. The aggregate now has its own cent limit.
- **P1 (validation):** The persisted-revision integration test failed because
  it expected canonical output without the newly required control evidence.
  It now exercises actual missing-proof rejection before isolating its
  database/revision/rendering assertions. No production approval is fabricated.

Regression reproductions failed against the original code for stale principal,
separator-containing archive output and accumulated rounding. After the fixes,
81 controls/monthly unit tests passed, including legitimate negative principal.
